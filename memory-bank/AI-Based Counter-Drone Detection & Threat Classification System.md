## Problem Statement 

Unauthorized UAVs pose escalating threats to **critical infrastructure, military installations, and public events** . Existing counter-drone solutions are: 

- Expensive — $500K-$2M per hardware unit 

- Fragmented — separate detection, classification, and response systems 

- Lacking real-time AI-driven threat classification 

Security personnel need an **integrated, affordable, and intelligent system** to detect, classify, and neutralize drone threats in real time.

## Key Innovation 

Unlike existing **hardware-heavy C-UAS systems** , AeroGuard AI is a **lightweight, deployable web application** with simulated intelligence. 

This makes counter-drone technology: 

- **Accessible** for hackathon prototyping 

- **Practical** for training simulations 

- **Ready** for future hardware integration 

## Your Solution & Its Novelty 

A **premium browser-based operations control center** combining: 

Built with **Vite + Vanilla JS** — zero proprietary dependencies, runs in any modern browser. 

- 360-degree radar visualizer with 60 FPS Canvas rendering 

- AI-powered threat classifier with multi-channel camera feeds 

- Real-time countermeasure control panel 

- Persistent event logging with LocalStorage
